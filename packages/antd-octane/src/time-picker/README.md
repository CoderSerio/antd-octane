# TimePicker (development source)

TimePicker is a native Octane, single-value, 24-hour Dayjs picker included from 0.1.0-alpha.8.
See the shared [date and time picker contract](../date-picker/README.md) for
value/draft handling, strict parsing, disabled times, steps, keyboard, Form,
portal containers, locale, and the deliberately unsupported advanced APIs.

`TimePickerProps` and `TimePickerRef` are exported from the package root.
